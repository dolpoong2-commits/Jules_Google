# ESP32 AI 데이터 수집기

## 1. 프로젝트 개요

이 프로젝트는 ESP32 관련 기술 자료를 웹에서 수집하여 AI 학습용 데이터셋을 구축하는 작업을 자동화하고 관리하기 위한 웹 애플리케이션입니다. 사용자는 웹 UI를 통해 스크래핑할 대상(웹사이트, GitHub 레포지토리)을 관리하고, 수집된 데이터를 확인하며, 로컬 PC에 다운로드할 수 있습니다.

## 2. 주요 기능

- **동적 대상 관리:** 웹 UI를 통해 스크래핑할 URL, 검색어, 수집 방식(일반/GitHub)을 동적으로 추가, 조회, 삭제할 수 있습니다.
- **듀얼 스크래핑 엔진:**
  - **헤드리스 브라우저:** Playwright를 사용하여 JavaScript로 렌더링되는 동적 웹사이트를 안정적으로 스크랩합니다.
  - **GitHub API:** GitHub 공식 API를 사용하여 레포지토리의 메타데이터와 소스 코드를 정확하고 효율적으로 수집합니다.
- **결과 확인 및 다운로드:** 스크래핑 결과가 UI에 실시간으로 표시되며, 사용자는 원하는 결과(웹페이지 HTML, GitHub 소스코드 .zip)를 선택하여 지정된 폴더에 다운로드할 수 있습니다.
- **다양한 UI 테마:** 사용자의 취향에 맞춰 '썬라이징', '다크 모드', '라이트 모드', '레트로 터미널', '사이버펑크', '미니멀리즘' 등 총 6가지의 시각적 테마를 제공합니다.

## 3. 설치 및 개발 환경 실행 (단일 사용자용)

이 섹션은 개발자가 직접 자신의 PC에서 개발 환경을 설정하고 서버를 실행하는 방법을 안내합니다.

### 1단계: 소스 코드 다운로드

이 프로젝트의 모든 소스 코드를 다운로드합니다.

### 2단계: Python 의존성 설치

프로젝트 실행에 필요한 파이썬 라이브러리들을 설치합니다. 터미널(명령 프롬프트)을 열고, 프로젝트 폴더로 이동한 뒤 다음 명령어를 실행하세요.

```bash
pip install -r requirements.txt
```

### 3단계: Playwright 브라우저 드라이버 설치

헤드리스 브라우저 기능에 필요한 웹 브라우저 실행 파일들을 설치합니다. 이 과정은 몇 분 정도 소요될 수 있습니다.

```bash
playwright install
```

### 4단계: 웹 서버 실행

모든 설치가 완료되면, 다음 명령어를 사용하여 Flask 웹 서버를 시작합니다.

```bash
python web_scraper_ui/app.py
```

서버가 성공적으로 시작되면, 터미널에 `Running on http://127.0.0.1:5001`와 같은 메시지가 표시됩니다.

### 5단계: 애플리케이션 접속

웹 브라우저를 열고 주소창에 `http://127.0.0.1:5001`을 입력하여 애플리케이션에 접속합니다.

## 4. 사내 배포를 위한 패키징 및 실행 방법 (Windows 기준)

이 섹션은 Python이나 개발 환경에 익숙하지 않은 동료에게 프로그램을 배포하는 방법을 안내합니다.

### 방법 1 (안정성 및 권장): 시작 스크립트(`start.bat`)를 이용한 실행

이 방법은 프로젝트 폴더 전체를 압축하여 전달하는 가장 안정적이고 권장되는 방식입니다. 사용자는 스크립트 파일을 더블클릭하기만 하면 모든 설정이 자동으로 이루어집니다.

**배포 절차:**
1.  이 프로젝트 폴더 전체를 하나의 `.zip` 파일로 압축하여 동료에게 전달합니다.
2.  사용자는 받은 `.zip` 파일의 압축을 풉니다.
3.  사용자는 압축 해제된 폴더 안에 있는 **`start.bat` 파일을 더블클릭하여 실행**합니다.

**`start.bat` 스크립트의 자동 작업 내용:**
- Python 설치 여부를 확인하고, 미설치 시 안내 메시지를 출력합니다.
- `venv`라는 이름의 Python 가상환경을 자동으로 생성합니다.
- `requirements.txt`에 명시된 모든 라이브러리(Flask, Playwright 등)를 가상환경 내에 설치합니다.
- Playwright가 사용할 웹 브라우저 드라이버를 자동으로 설치합니다.
- 모든 설정이 완료되면 웹 서버를 실행하고, 사용자가 접속할 수 있는 주소를 안내합니다.

### 방법 2: 단일 실행 파일(`.exe`) 생성

이 방법은 모든 소스 코드와 라이브러리를 하나의 `.exe` 파일로 묶어 배포하는 간편한 방식입니다.

**`.exe` 파일 생성 절차 (개발자용):**
1.  **PyInstaller 설치:** 터미널에서 다음 명령어를 실행하여 PyInstaller를 설치합니다.
    ```bash
    pip install pyinstaller
    ```
2.  **실행 파일 빌드:** 프로젝트의 루트 폴더(이 `README.md` 파일이 있는 위치)에서 다음 명령어를 실행합니다.
    ```bash
    pyinstaller --name "ESP32_Scraper" --onefile --windowed --add-data "web_scraper_ui/templates:templates" --add-data "web_scraper_ui/static:static" web_scraper_ui/app.py
    ```
    - `--name`: 생성될 `.exe` 파일의 이름을 지정합니다.
    - `--onefile`: 모든 파일을 하나의 실행 파일로 묶습니다.
    - `--windowed`: 실행 시 뒤에 검은색 터미널 창이 나타나지 않도록 합니다.
    - `--add-data`: `templates`와 `static` 폴더를 실행 파일 안에 포함시켜 UI가 올바르게 표시되도록 합니다. (Windows에서는 경로 구분자를 `;`으로, macOS/Linux에서는 `:`으로 사용합니다.)

3.  **배포:** 빌드가 성공적으로 완료되면, `dist` 폴더 안에 `ESP32_Scraper.exe` 파일이 생성됩니다. 이 파일을 동료에게 전달하면 됩니다.

**`.exe` 파일 실행 시 주의사항 (배포 받은 사용자용):**
- `.exe` 파일을 처음 실행하기 전에, Playwright 브라우저 드라이버를 수동으로 설치해야 할 수 있습니다. 터미널(명령 프롬프트)을 열고 다음 명령어를 실행해야 합니다.
  ```bash
  playwright install
  ```
- 이 방식은 Playwright와 같은 복잡한 라이브러리와 충돌하거나 예기치 않은 오류가 발생할 수 있으며, 파일 크기가 수백 MB로 매우 클 수 있습니다. 안정적인 사용을 위해서는 **방법 1을 권장**합니다.

## 5. 기술적 참고사항

- **백엔드:** Flask (Python)
- **프론트엔드:** HTML, CSS, Vanilla JavaScript
- **스크래핑 엔진:** Playwright (헤드리스 브라우저), Requests (GitHub API)
