## 7개 AI 답변 자동 수집 및 토론 시스템 사용자 가이드 (instructions.txt)

안녕하세요! 이 스크립트는 챗지피티, 제미나이, 클로드 등 7대 AI가 하나의 주제에 대해 함께 토론하고, 그 내용을 종합하여 최적의 사업 기획안이나 해결책을 만들어주는 '자동화된 AI 토론방' 시스템입니다.

이제 각 AI에게 따로 질문할 필요 없이, 이 스크립트 하나로 집단 지성의 힘을 활용해보세요.

### 주요 기능
1. **싱글 통합 프로필:** 7개 사이트의 로그인 정보를 하나의 프로필 폴더(`unified_ai_profile`)에서 통합 관리하여 컴퓨터 자원을 절약하고 속도를 높였습니다.
2. **자동 심화 토론:** [1차 답변 수집] -> [AI의 핵심 요약 및 질문 제안] -> [사용자 선택] -> [2차 심화 토론]의 과정을 자동으로 진행합니다.
3. **최종 기획안 생성:** 토론이 끝나면 비즈니스, 교육, 기술 등 원하는 테마를 선택하여 "최종 프로젝트 기획안"을 자동으로 생성합니다.

---

### 1단계: 필수 프로그램 설치 (최초 1회)

스크립트를 실행하기 위해 딱 두 가지만 설치하면 됩니다.

**A. Python 설치**
- 아직 Python이 없다면, [python.org](https://www.python.org/downloads/)에 접속하여 최신 버전을 다운로드하고 설치해주세요.
- **중요:** 설치 과정에서 "Add Python to PATH" 또는 "Add python.exe to PATH" 라는 체크박스가 보이면 **반드시 체크**하고 설치를 진행해주세요.

**B. Playwright 라이브러리 및 브라우저 설치**
- Python 설치 후, '명령 프롬프트(CMD)' 또는 '터미널'을 열어 아래 두 명령어를 차례대로 입력하고 엔터를 눌러주세요.

   ```bash
   pip install playwright
   ```
   (설치가 완료될 때까지 잠시 기다립니다)

   ```bash
   playwright install
   ```
   (스크립트가 사용할 웹 브라우저들을 자동으로 설치합니다. 시간이 조금 걸릴 수 있습니다.)

### 2단계: 스크립트 실행 및 최초 로그인

이제 모든 준비가 끝났습니다. 스크립트를 실행해 보겠습니다.

**A. 스크립트 실행**
- '명령 프롬프트(CMD)' 또는 '터미널'에서, `ai_automation_script.py` 파일이 있는 폴더로 이동합니다.
- 아래 명령어를 입력하고 엔터를 누르면 스크립트가 시작됩니다.

   ```bash
   python ai_automation_script.py
   ```

**B. 최초 로그인 (중요!)**
- 스크립트가 실행되면 브라우저 창이 하나 열리고, 7개의 AI 사이트를 순서대로 방문하거나 탭을 엽니다.
- **각 사이트(ChatGPT, Gemini 등)에 접속될 때마다 로그인이 되어있는지 확인하고, 안 되어 있다면 직접 로그인해주세요.**
- 한 번 로그인해두면 정보가 `unified_ai_profile` 폴더에 저장되어 다음부터는 로그인 과정 없이 바로 토론이 시작됩니다.

### 3단계: 토론 진행

1. **주제 입력:** 프로그램이 "토론 주제를 입력하세요"라고 물으면 원하는 주제를 입력합니다.
2. **1차 토론:** 7개 AI가 동시에 해당 주제에 대해 답변합니다.
3. **중간 점검:** ChatGPT가 1차 답변들을 요약하고, 더 깊은 토론을 위한 '후속 질문 3가지'를 제안합니다.
4. **심화 질문 선택:** 제안된 질문 중 하나를 번호로 선택하거나, 직접 새로운 질문을 입력합니다.
5. **2차 토론:** 선택한 심화 질문으로 AI들이 다시 토론을 벌입니다.
6. **최종 테마 선택:** 토론 내용을 바탕으로 만들고 싶은 결과물의 종류(예: 사업 기획서, 기술 명세서 등)를 선택합니다.

### 4단계: 결과 확인

- 모든 과정이 끝나면 폴더에 다음 파일들이 생성됩니다.
    - `round_1_responses.txt`: 1차 토론 내용
    - `round_2_responses.txt`: 2차 심화 토론 내용
    - `final_project_plan.txt`: 최종 완성된 기획안/보고서

이제 이 가이드를 따라 AI들의 집단 지성을 손쉽게 활용해보세요!
