## 7개 AI 답변 자동 수집 스크립트 사용자 가이드 (instructions.txt)

안녕하세요! 이 스크립트는 7개의 주요 AI(챗지피티, 제미나이, 클로드, 코파일럿, 뤼튼, 그록, 젠스파크)에게 동일한 질문을 하고, 모든 답변을 `ai_responses.txt` 파일 하나로 모아주는 자동화 도구입니다.

아래 안내에 따라 차근차근 진행하시면 손쉽게 사용하실 수 있습니다.

### 1단계: 필수 프로그램 설치 (최초 1회)

스크립트를 실행하기 위해 딱 두 가지만 설치하면 됩니다.

**A. Python 설치**
- 아직 Python이 없다면, [python.org](https://www.python.org/downloads/)에 접속하여 최신 버전을 다운로드하고 설치해주세요.
- **중요:** 설치 과정에서 "Add Python to PATH" 또는 "Add python.exe to PATH" 라는 체크박스가 보이면 **반드시 체크**하고 설치를 진행해주세요.

**B. Playwright 라이브러리 및 브라우저 설치**
- Python 설치 후, '명령 프롬프트(CMD)' 또는 '터미널'을 열어 아래 두 명령어를 차례대로 입력하고 엔터를 눌러주세요.

   ```bash
   pip install playwright
   ```
   (설치가 완료될 때까지 잠시 기다립니다)

   ```bash
   playwright install
   ```
   (스크립트가 사용할 웹 브라우저들을 자동으로 설치합니다. 시간이 조금 걸릴 수 있습니다.)

### 2단계: 스크립트 실행 및 최초 로그인

이제 모든 준비가 끝났습니다. 스크립트를 실행해 보겠습니다.

**A. 스크립트 실행**
- '명령 프롬프트(CMD)' 또는 '터미널'에서, `ai_automation_script.py` 파일이 있는 폴더로 이동합니다.
- 아래 명령어를 입력하고 엔터를 누르면 스크립트가 시작됩니다.

   ```bash
   python ai_automation_script.py
   ```

**B. 질문 입력**
- 스크립트가 실행되면 "모든 AI에게 물어볼 질문을 입력하세요:" 라는 메시지가 나타납니다.
- 여기에 원하시는 질문을 입력하고 엔터를 누르세요. (만약 아무것도 입력하지 않으면 기본 질문이 실행됩니다.)

**C. AI 서비스 최초 로그인 (가장 중요한 과정!)**
- 스크립트가 각 AI 웹사이트에 차례대로 접속하면서 자동으로 웹 브라우저 창을 엽니다.
- **최초 실행 시에는 각 사이트의 로그인이 필요합니다.** 스크립트가 "로그인이 필요합니다. 30초 동안 로그인을 기다립니다..." 메시지를 보여줄 때, 열려있는 브라우저 창에서 직접 이메일/비밀번호를 입력하거나 구글/애플 계정으로 로그인해주세요.
- **한 번만 로그인하면, 그 정보는 `user_data` 폴더에 안전하게 저장되어 다음 실행부터는 자동으로 로그인됩니다.** (ChatGPT, Gemini, Claude 등 각 AI별로 폴더가 생성됩니다.)
- 7개 AI 모두에 대해 이 과정을 한 번씩만 완료하면 됩니다.

### 3단계: 결과 확인

- 스크립트가 모든 작업을 마치면, "모든 AI의 답변을 'ai_responses.txt' 파일에 저장했습니다." 라는 메시지가 나타납니다.
- `ai_automation_script.py` 파일이 있는 폴더에 `ai_responses.txt` 파일이 생성됩니다.
- 이 파일을 열면 7개 AI의 모든 답변이 보기 좋게 정리되어 있습니다.

---
**※ 문제 해결**
- **오류가 발생하나요?** 대부분의 오류는 웹사이트 구조 변경으로 인해 발생합니다. 또는 인터넷 연결이 불안정할 때 발생할 수 있습니다.
- **로그인이 계속 풀리나요?** 일부 AI 서비스는 보안 정책상 주기적으로 재로그인을 요구할 수 있습니다. 그럴 경우, 다시 한번 수동으로 로그인해주시면 됩니다.

이제 이 가이드를 따라 AI들의 집단 지성을 손쉽게 활용해보세요!
